Your chat stays on this device. Everything happens inside this browser tab. The page's security policy blocks all network requests, so nothing can be uploaded, even by accident. You can also disconnect from the internet before you open a chat.
How do I export a chat from WhatsApp?
  1. Open the chat on your phone.
  2. iPhone: tap the contact's name → Export Chat → Attach Media.
    Android: ⋮ → More → Export chat → Include media.
  3. Save the file to your computer, for example with AirDrop, a USB cable or Files. Avoid sending it to yourself through a cloud service if you want it to stay fully offline.
  4. Open the .zip here. You don't need to unzip it. An unzipped folder works too, and so does a .txt file together with its media files.
